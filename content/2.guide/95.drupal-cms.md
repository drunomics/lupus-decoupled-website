# Drupal CMS with Lupus Decoupled

[Drupal CMS](https://www.drupal.org/project/cms) is Drupal's user-friendly distribution aimed at marketers and content teams. Lupus Decoupled supports it via site templates, providing a fully decoupled setup out of the box.

The [Lupus Decoupled Starter](https://git.drupalcode.org/project/lupus_decoupled_starter) is a ready-to-use Drupal CMS site template that bundles:
- **Drupal CMS base setup**: content types, editorial workflow, and other Drupal CMS defaults
- **Lupus Decoupled Recipe**: core modules and configuration
- **Lupus Decoupled Canvas**: Canvas visual editor integration
- **Lupus CSR**: client-side rendering theme (set as default)

## Installation

Install the starter as a site template when setting up Drupal CMS, or apply it manually:

```bash
composer require drupal/lupus_decoupled_starter
drush site-install ../recipes/lupus_decoupled_starter
```

For a full local setup with DDEV:

```bash
mkdir my-drupal-site && cd my-drupal-site
ddev config --project-type=drupal11 --docroot=web
ddev composer create-project drupal/cms
ddev composer require drupal/lupus_decoupled_starter
drush site-install ../recipes/lupus_decoupled_starter
ddev launch
```

## Client-Side Rendering

The starter uses [Lupus CSR](https://www.drupal.org/project/lupus_csr) (Client-Side Rendering) as the default theme. This means:
- The Nuxt frontend is pre-built and served directly from Drupal, with no separate frontend server needed
- The frontend JavaScript runs in the browser and fetches content from the CE API at `/ce-api/...` on the same origin, so no CORS configuration is required
- This is ideal for getting started quickly, but **not recommended for SEO-critical production sites** (use SSR instead)

All Lupus Decoupled documentation applies regardless of whether you use CSR or SSR. The rendering mode is a deployment detail, not a content architecture decision.

## Customizing a CSR Theme

To customize the frontend appearance, create a Drupal sub-theme of `lupus_csr` and place your SPA build output in a `dist/` directory. See the [Lupus CSR](https://www.drupal.org/project/lupus_csr) project page for details.

## Switching to Server-Side Rendering

To move from CSR to SSR:
1. Set up a separate Nuxt server (or deploy serverlessly at the edge)
2. Disable Lupus CSR as the active theme and switch to a standard Drupal theme for the backend
3. Configure the Lupus Decoupled frontend URL to point to your Nuxt server
4. Refer to [Rendering modes](/nuxt/rendering-modes) and [Deployment strategies](/deployment/deployment-strategy) for options

## Creating New Site Templates

The Lupus Decoupled Starter is designed to serve as a template for building new Drupal CMS site templates. See the [Site Templates](/advanced-topics/site-templates) page for guidance.
